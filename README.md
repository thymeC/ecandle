# eCandle · 电子生日蜡烛

没有打火机也能过生日：在浏览器里点燃蛋糕蜡烛，用麦克风吹灭，吹灭后会有庆祝特效。可选背景音乐（合成版《生日快乐》旋律）。

## 功能

- **多根蜡烛**或**数字蜡烛**（按年龄显示，如 18 → 1 和 8）
- 一键点燃，或点击单根蜡烛点火
- **麦克风吹气**：检测吹气音量，逐根吹灭蜡烛
- 全部吹灭后：**彩纸特效** + 「生日快乐」 overlay
- 开关：**背景音乐**（默认开启，需在用户交互后播放）

## 本地运行

纯静态页面，任意静态服务器即可：

```bash
cd /path/to/ecandle
python3 -m http.server 8080
```

浏览器打开 `http://localhost:8080`。麦克风功能需要 **HTTPS** 或 **localhost**。

也可直接双击 `index.html` 打开（部分浏览器可能限制麦克风）。

## 技术说明

- HTML / CSS / 原生 JavaScript（无构建步骤）
- Web Audio API：背景音乐与麦克风电平分析
- Canvas： confetti 粒子特效
